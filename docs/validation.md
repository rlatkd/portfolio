## 최종 실행 결과

- `npm run check`: 타입 검사, 회귀 검사 8개, 프로덕션 빌드 통과.
- `npm run test:e2e`: 실제 Chrome 검사 8개 통과. 그중 한 검사는 50개 글 전체를 순회합니다.
- `pnpm audit --prod`: 알려진 운영 의존성 보안 경고 0건.
- CSS 관련 보안 패치 전후 생성된 CSS 내용 동일.
- `git diff --check`: 통과.
- Next.js 16의 Turbopack 내부 프로세스 통신이 현재 실행 환경에서 차단돼 공식 지원 Webpack 모드로 개발·빌드를 구성했습니다.

## 남아 있는 범위와 제한

- 색상 대비, 화면 높이에 따른 폰트 축소, About 카드 구성, 섹션 순서 등 디자인 변경은 사용자 요청에 따라 보류했습니다.
- 원문 자체의 빈 이미지 주소 2곳은 원문 그대로 보존했습니다. 외부 이미지 서버의 가용성까지 보장하지는 않습니다.
- 개발 의존성 전체 검사에는 `braces@3.0.3`의 GHSA-vfj7-8cjw-p6xm 경고 1건이 남습니다. 공식 권고에 수정 버전이 없으며 레지스트리에도 3.0.4가 없습니다. 런타임 의존성에는 포함되지 않고, 이 프로젝트의 Tailwind 빌드는 저장소에 고정한 glob만 사용합니다. 경고를 숨기거나 존재하지 않는 버전을 지정하지 않았습니다. 후속 패치 또는 안전한 빌드 도구 전환이 필요합니다.
- Search Console·네이버 서치어드바이저 계정 상태, 실제 색인 결과, 운영 GA 수집과 실사용 Core Web Vitals는 계정·배포 환경에서 별도 확인해야 합니다.
