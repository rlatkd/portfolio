# 2026-10-16 측정 소스 최신 여부 재확인

- 이전 측정의 로컬 HEAD는 47df549, 조회 시 원격 main은 915fd9232efbea6ac97f90f2ff61c90bee41c1fd로 달랐음. 공개 커밋 존재 여부 확인은 최신 여부 확인을 대신하지 못했음.
- 원격 main을 /tmp의 별도 깨끗한 체크아웃으로 확보. 로컬과 원격의 backend/app Python 소스 44개를 비교한 결과 차이 0개. 이전 캐시·일봉·상관 함수 파일 해시도 동일.
- 원격 체크아웃에서 실험 재실행하고 공개 JSON 및 근거 페이지 갱신. 로컬 up-quant 작업 디렉터리는 갱신하거나 수정하지 않음.
- 측정 스크립트에 expected-commit 필수 인수와 백엔드 변경 검사 추가. verify-remote 옵션은 실행 직전 원격 main과 일치하지 않으면 중단. JSON에 원격 ref·SHA·확인 시각 기록.
- “최신”은 조회 시점에 한정되며, 이번 실험이 과거 HTTP 응답 수치 재현이나 운영 배포 검증을 뜻하지는 않음.
- 소개된 타 프로젝트 전체 실행은 포트폴리오 검수의 필수 조건이 아님. 소스·환경이 없는 프로젝트는 공개 자료와 사용자 확인 내용을 기준으로 서술·출처·화면을 검수하고, 직접 확인하지 못한 성능은 미검증 범위를 명시.
