# 2026-10-26 개선 반영 기록

## 반영 범위

- `career-data.ts`: 수행 과제의 날짜·담당 범위·메인 요약·이력서 상세 내용 공통 관리.
- `profile-data.ts`: 학력·교육·수상·자격의 공통 원본. 이력서에서 기간·기관 참조.
- 프로젝트는 3.5초 자동 전환과 진행 게이지 유지. 마우스·키보드 포커스·모션 감소 설정에서는 멈춤. 사용자 요청으로 정지·재생 버튼 제거. 수동 전환·스와이프·HTML 제목·역할 표시와 터치 영역 개선.
- 모바일·노트북용 접이식 글 목차, 검색·필터 목록 복귀, 검색 범위 안내·초기화.
- 사용자 요청에 따라 별도 작성 요약문을 삭제. 목록·추천·RSS·검색 설명은 원본 본문의 앞 160자를 자동 발췌. 추천 3개와 관련 글 지정 기능 유지.
- 이력서 페이지·배율 URL 복원과 화면 크기에 따른 최소 배율 보장.
- 본문 바로가기·포커스·모션 감소·복사 실패 안내·404 목적지 보완.
- 블로그 본문은 기존 50편의 원문 그대로 제공. 임의로 적용했던 정정 표시·본문 대체와 추가 실무 글 3편은 사용자 요청으로 원복.
- up-quant의 공개 함수 벤치마크와 과거 HTTP 응답 수치 구분.
- 보안 헤더 적용. CSP는 보고 모드이며 정적 렌더링 유지.
- GA4에 이력서 열기·저장소 이동·메일 앱 열기를 고정 이벤트 이름으로 구분. 이메일·검색어·링크 문구를 이벤트 파라미터에 넣지 않음. 페이지 URL의 기존 자동 수집 정책은 별개.
- CI 중복 취소·시간 제한·실패 trace와 스크린샷 보관. 모바일 WebKit·일반 모션·이력서 넘침 검사 추가.
- 운영 점검에 `/resume`와 의도된 noindex 확인 추가. 주간 외부 링크·이미지 검사 결과 보관.

## 외부 환경에서 마무리할 항목

- Search Console·네이버에서 실제 색인 상태와 제외 사유 확인.
- 실제 iPhone Safari·Android Chrome에서 확대·스크롤·회전·인쇄·공유 확인. WebKit 에뮬레이션은 실제 기기 검사를 대체하지 않음.
- 배포 후 Search Console·Speed Insights에서 실사용 Core Web Vitals 확인. 이미지·글꼴 최적화는 측정에 따라 결정.
- CSP 보고 모드: 운영 브라우저 콘솔에서 폰트·GA4·Vercel 도메인 위반 확인 후 강제 모드 전환 판단. 서버 보고 수집 endpoint는 구성하지 않았으므로 보고서가 자동 저장되지는 않음.
- GA4에서 `resume_open`, `project_repository_open`, `contact_email_open` 수집과 데이터 보관 설정 확인. 메일 앱 열기는 문의 전송 완료가 아님.
- GitHub 예약 워크플로·Vercel 배포 알림 수신 확인. 가용성 검사를 30분 간격으로 단축했으며 예약 실행 지연이나 짧은 장애까지 보장하지 않음. 즉시 감지가 필요하면 별도 외부 모니터 도입.
- 전자계약 누적 집계 시점·문의 해소 관찰 기간은 추가 근거 확보 후 갱신. 임의의 기간·값을 만들지 않음.
- 외부 이미지의 장기 보관·자체 호스팅 여부 결정. 주간 점검은 제공되는 이미지의 원본과 출처 매니페스트를 복구용 아티팩트로 30일 보관한다. 제공 중단된 이미지는 복구하지 못하며 영구 백업·자체 호스팅은 아님.
- 블로그 글의 사실 검토와 문장 수정은 작성자 확인을 거쳐 별도 진행. 현재 사이트·Velog 본문에는 이번 검수의 내용 수정을 적용하지 않음.
- 커밋·푸시·운영 배포는 이번 로컬 수정과 별개.

## 콘텐츠 운영

블로그 본문은 `src/shared/content/posts/*.mdx`와 Velog 원문 스냅샷으로 관리한다. 글을 임의로 새로 쓰거나 실무 서사를 보충해 공개하지 않는다.

관련 글 지정은 `related-posts.ts`에서 관리한다. 원문 파일 해시뿐 아니라 실제 제공 본문·수정일·글 개수가 원문과 일치하는지 검사한다. 메인에는 기존 글 중 발행일 기준 최신 3편을 표시한다.

검증 결과는 [검증 기록](validation.md)에 정리했다. 로컬 프로덕션 관측값은 `test-results/page-metrics.json`, 외부 자원 응답은 `test-results/external-links.json`·`external-images.json`에서 확인할 수 있다. 이 생성물은 Git에 포함하지 않는다.
